Ækasha is built on three principles. **Primordial performance:** WebGPU first, with the GPU as the
primary canvas for logic and rendering. **Modular infinity:** a modular ECS, so you bring in only
what you need. **Threaded reality:** physics and asset loading run on their own threads, so the
main thread stays free for the experience.

Each feature gets its own page here, with its example and its API.
