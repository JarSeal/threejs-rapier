Each example is a real scene in the app, in `src/app/examples/`, listed as "Example: …" in the
debug tools' scene dropdowns. Its page walks through the scene's code, included from the scene's
own files, so what you read is what runs.

New to Ækasha? Start with the [quick start](hub:examples#quick-start): it sets up the dev
environment and builds the smallest complete scene.
